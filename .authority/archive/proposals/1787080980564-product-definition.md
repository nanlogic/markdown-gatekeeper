# Product Definition

Markdown Gatekeeper is a local-first authority control layer for Markdown projects worked on by multiple humans, sessions, and LLMs.

Its job is not to choose the newest or longest document. It resolves authority per topic, exposes conflicts, and permits only one current revision for each topic.

The product preserves ordinary Markdown, local folders, and local Git. Remote Git, cloud storage, vector databases, and MCP are optional integrations rather than sources of truth.

The initial user is an individual using Claude and Codex across many sessions. The first commercial expansion, if dogfood succeeds, is a small AI-native team that needs identity, approval, audit, and shared publishing.
